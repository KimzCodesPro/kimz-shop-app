Step 01

Get the device's dimensions

React Native gives us a function called Dimensions.get('window') that returns the current screen width and height.

import { Dimensions } from "react-native";

const { width, height } = Dimensions.get("window");
width = 393
height = 852

Try switching to Landscape in the controls above — watch the numbers swap! That swap is the problem we need to solve.

Step 02

Identify short side & long side

We don't want our scaling to break when the user rotates the phone. So we figure out which dimension is shorter (regardless of orientation) and which is longer.

const [shortDimension, longDimension] =
  width < height ? [width, height] : [height, width];

How it runs RIGHT NOW with your values:

shortDimension = 393
longDimension = 852
✦ Notice

Toggle between Portrait and Landscape above — the raw width and height swap, but shortDimension and longDimension stay the same. That's the whole trick.

Step 03

The designer's mockup size

The designer built the Figma file at 440 × 956. Every value (a 200px button, 16px padding) is relative to that frame.

const guidelineBaseWidth  = 440;  // Figma frame width
const guidelineBaseHeight = 956;  // Figma frame height

This is the "reference point." We'll compare every device's real size to these numbers.

Step 04

The scale ratios

Before we can scale anything, we need to know how much smaller (or bigger) this device is compared to the mockup.

HS ratio = shortDimension ÷ guidelineBaseWidth = 393 ÷ 440 → 0.89
VS ratio = longDimension ÷ guidelineBaseHeight = 852 ÷ 956 → 0.89

A ratio of 1.00 means the device matches the mockup exactly. 0.85 means everything shrinks ~15%. 1.10 means everything grows 10%.

Step 05

HS — Horizontal Scale

Now the actual function. Multiply your design value by the HS ratio, round to a clean integer.

export const HS = (size) =>
  Math.round((shortDimension / guidelineBaseWidth) * size);

Calling HS(200) right now:

HS(200) = round((393 ÷ 440) × 200)      = round(0.89 × 200)      = round(178.6)      → 179 px

Change the "Test value" in the controls above to see this update live.

Step 06

VS — Vertical Scale

Same idea, but using the long side of the device against the mockup height.

export const VS = (size) =>
  Math.round((longDimension / guidelineBaseHeight) * size);

Calling VS(200) right now:

VS(200) = round((852 ÷ 956) × 200)      = round(0.89 × 200)      = round(178.2)      → 178 px
Step 07

FS — Font Scale (with dampening)

Fonts need special treatment. If we used HS for fonts, they'd shrink too aggressively on small phones (unreadable) and grow too much on big phones (chunky). So we use a dampening factor that moves the value only PARTWAY toward the scaled version.

export const FS = (size, factor = 0.5) =>
  size + (HS(size) - size) * factor;

Calling FS(16) right now:

Step 1: HS(16) = 14 Step 2: gap = HS(size) − size = 14 − 16 = −2 Step 3: dampened gap = gap × 0.5 = −1 Step 4: FS = size + dampened gap = 16 + (−1) = 15 px
✦ Why factor = 0.5

Factor 0.5 means "move halfway toward the HS value." Result: fonts shrink half as much as the screen, so text stays readable on small phones.

Step 10

The whole thing, together

Save this as utils/scalling.ts in your project:

import { Dimensions } from "react-native";

// 1. Designer's Figma frame size
const guidelineBaseWidth  = 440;
const guidelineBaseHeight = 956;

// 2. Get the device dimensions
const { width, height } = Dimensions.get("window");

// 3. Lock short and long sides (handles rotation)
const [shortDimension, longDimension] =
  width < height ? [width, height] : [height, width];

// 4. Horizontal Scale — for width, paddings, icon sizes, squares
export const HS = (size) =>
  Math.round((shortDimension / guidelineBaseWidth) * size);

// 5. Vertical Scale — for height, vertical paddings, lineHeight
export const VS = (size) =>
  Math.round((longDimension / guidelineBaseHeight) * size);

// 6. Font Scale — for fontSize only (dampened scaling)
export const FS = (size, factor = 0.5) =>
  size + (HS(size) - size) * factor;
✦ Usage cheat sheet

HS → width, paddingHorizontal, marginHorizontal, icon size (both dims), squares, circles, gap (row), borderRadius on rectangles, borderWidth.

VS → height, paddingVertical, marginVertical, lineHeight, top/bottom, gap (column), borderRadius on pills (half of height).

FS → fontSize ONLY.
